# Загрузка каруселей Камилы

1. Подготовьте ZIP с отдельными PNG в правильном порядке, например `2026-10-26-carousel.zip`.
2. Загрузите ZIP в папку `incoming/` через GitHub → Add file → Upload files.
3. GitHub Actions автоматически извлечёт изображения в `images/2026/10/`.
4. Проверьте результат в GitHub Actions и в папке изображений.

Важно: этот механизм автоматизирует распаковку **после загрузки ZIP в GitHub**, но не передаёт файлы из ChatGPT в GitHub сам по себе. Для полностью автоматической передачи понадобится отдельный сервис с защищённым доступом.
