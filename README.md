# Kamila Astrology Content

Публичный репозиторий готовых материалов астрологического проекта «Камила».

- `images/` — изображения для публикаций и публичные ссылки для Metricool.
- `captions/` — подписи к постам.
- `automation/` — инструкции и будущие сценарии автоматизации.

## Публикация через Metricool

1. Подготовить и утвердить изображение и подпись.
2. Загрузить изображение в `images/YYYY/MM/`.
3. Получить публичную ссылку `https://raw.githubusercontent.com/elenadanchenkomn/kamila-astrology-content/main/images/YYYY/MM/filename.jpg`.
4. Передать ссылку, текст, площадку и время публикации в Metricool.

Не добавляйте в репозиторий пароли, API-токены или персональные данные. Астрологические публикации носят развлекательный и рефлексивный характер.
