# Автоматизация публикаций

Планируемый поток: подготовка текста и изображения → проверка → загрузка изображения в `images/` → формирование прямой ссылки → постановка поста в очередь Metricool.

GitHub сам по себе не создаёт изображения и не публикует посты. Для автоматической работы потребуется отдельный workflow и доступ к API публикации, с секретами в GitHub Actions Secrets (не в репозитории).
